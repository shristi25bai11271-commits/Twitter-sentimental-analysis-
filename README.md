# Twitter Sentiment Analysis 😍😒😐

This is a beginner-level Natural Language Processing (NLP) project built using Python and Scikit-learn. The project classifies tweets as Positive, Negative, or Neutral using a machine learning model.

##🎯🎯 Project Overview

The main goal of this project is to understand how sentiment analysis works using text data. The program takes tweet text as input and predicts its sentiment.

Example:
Input:
I love this movie
Output:
positive


##👌👌 Features

- Classifies tweets into:
  - Positive
  - Negative
  - Neutral
- Uses Machine Learning for prediction
- Accepts custom user input
- Beginner-friendly implementation

## 🧑‍💻🧑‍💻Technologies Used

- Python
- Pandas
- Scikit-learn

Libraries used:
- CountVectorizer
- Multinomial Naive Bayes
- Train-Test Split

## Machine Learning Concepts Used

### 1. CountVectorizer
Converts text into numerical format so the machine learning model can understand it.

### 2. Multinomial Naive Bayes
A simple and effective algorithm commonly used for text classification tasks.

### 3. Train-Test Split
Splits the dataset into training and testing data to evaluate model performance.
